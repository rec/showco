# Deferred and proposed features

These are optional features. Reliability findings are tracked in
[issues.md](issues.md).

## Deferred keyboard and footswitch controls

Provide configurable shortcuts for marking a moment, starting the next song,
and opening the performance screen. Start with keyboard events and
keyboard-emulating pedals. Ignore input while typing and suppress key repeat.
MIDI pedals would need separate bindings and a test screen.

## Lighting cue extensions

The current Lighting page runs an ordered list of manual lyte cues. Remaining
proposals include independent look selection, an explicit blackout control,
and configurable brightness limits and transitions if lyte can support them.
Keep timing and playback in lyte.

## Highlights and stream presentation

Offer a single highlight control with separate outcomes for a recs marker and
an optional streamO clip. A failed clip request should leave the marker intact.
Preview song titles or interval announcements before sending them. A read-only
overlay could show approved song titles and interval messages.

## Show report additions

Extend `showco report` with set-list markers, recovery history, service versions,
and operator notes where available. Keep observations and verified media
evidence distinct.

None.
