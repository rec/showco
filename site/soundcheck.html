Guided soundcheck

Checking the current equipment...

Select the inputs you expect to record. Beginning soundcheck clears earlier results; it does not start playback, recording, or light output.

1. Disk and inputs

Confirm the intended disk is mounted. Make sound on every selected input, then check for signal and clipping.

2. Record a sample

Resuming records into the current recs session. Make a few seconds of sound, check that recorded audio advanced, then explicitly pause to finish the sample. Recording stays paused until you resume it. No new session is created.

3. Hear the sample

Open Playback, select the just-recorded sample and listen. Enter the session or file you heard below, then confirm playback. A counter increase alone does not prove playback.

4. Optional output checks

Test lights is explicit and leaves lights off. For streaming, inspect the live stream from another device. Use Actions to operate streamO if needed. Disabled outputs may be skipped with a reason. Cable testing remains outside this workflow until hardware validation is complete.

Results

Finish by resuming recording if required and checking Performance. A day, observed device, mount, service, or saved recs configuration change invalidates checks. Mixer gain changes outside showCo must be followed by a fresh soundcheck.
